What it does
An OCR-powered document processing tool that extracts, structures, and makes searchable the content of scanned or photographed documents using Machine Learning and Computer Vision pipelines.
The challenge
Built under hackathon time constraints with a team. The core difficulty was getting OCR accuracy high enough to be useful on real-world document noise — skewed scans, mixed fonts, uneven lighting.
What I learned
How to scope a project ruthlessly. Preprocessing matters more than model choice. And that demonstrating a working MVP under pressure teaches more than months of solo study.

Project 02
Drone Flight Simulator
JavaScript · Physics Engine · 3D Terrain
Role
Web Systems Engineer
Company
Certanity (Space)
Status
Active
What it is
A browser-based drone flight simulator built for certanity.com — a space-born company. Features Perlin noise terrain generation, physics-based flight mechanics, a minimap, and three difficulty tiers (Basis, Max, Pro). Entirely vanilla JS, no framework.
Engineering challenges
Ground collision detection against dynamic terrain height, canvas sizing bugs triggered by hidden parent containers at startup, performance degradation from double RAF loops and per-frame allocations — the kind of problems that only show up at runtime.
What I own
As Web Systems Engineer, I own the simulator's front-end architecture and runtime performance. Debugging here means reading browser profiler traces, not guessing — a discipline that's reshaping how I approach all web work.

06 Leadership

Athenaeum Club,
JNTUK

I started the Athenaeum Club with one frustration: most technical knowledge at college lives in silos. Second-years know things first-years need, third-years know things second-years need — and none of it gets shared formally.

The club is a peer-led skill exchange. No hierarchy, no gatekeeping. Anyone who knows something worth teaching can run a session. Anyone who wants to learn something attends. The rule is simple: you contribute what you know.

As leader, I set the culture and direction, handle logistics, and personally run sessions on design, Python, and productivity tooling. The model works because it's built on mutual respect — not authority.

How it works
01
Peer-led sessions
Members host workshops on their strongest skills — Python, UI design, competitive programming, video editing. No age requirement to teach.
02
Flat knowledge network
All years attend together. A first-year who's good at Blender teaches a final-year who's never touched it. The hierarchy is expertise, not seniority.
03
Community, not club
The goal isn't events on a calendar. It's connections that last beyond college — people who build things together and hold each other accountable.
Recent activity
Drafted promotional content for Microsoft AI Skills Fest 2026 — took the club's voice to an industry-level event.
